# Team Workflow

## Branch and Commit Workflow
1. Pull latest changes from `main`.
2. Create a branch: `feature/<name>-<task>`.
3. Make focused changes and commit with clear messages.
4. Open a pull request and request review from Tayo.
5. Merge after approval.

## Work Cadence
- One formal check-in meeting per week.
- Mid-week async update in team chat.
- Immediate escalation for blockers longer than 24 hours.

## Definition of Done
- Work is in correct folder.
- Work is documented (what, why, and how to use).
- Another member can run/understand it.
- The change is reviewed before merge.
